# BioSketch 科研配图

给它一个研究主题（可附上参考图），它会先理出内容大纲，再一张一张把科研配图画出来。

三步上手操作指南：装好技能 → 录入授权码 → 说出需求，自动逐页出图

就按最上面那张图的三步来：**装好技能 → 录入授权码 → 说出需求**，剩下的它自动完成。

---

## 它能做什么

- 机制图、通路图、图解、Graphical Abstract、期刊封面式插画、对照示意图……
- 内置多种风格可选，也可以完全不要风格约束。
- 你可以把参考图一并给它（最多 5 张），它会参考这些图的风格与内容。

## 开始用（三步）

与最上面那张图一一对应：

1. **装好技能**：把整个技能文件夹放好即可，不用装其他东西。
2. **录入授权码**：授权码是你的「通行证」，填一次就好（见下方「关于授权码」）。
3. **说出需求**：告诉它你的研究主题，并在它列出的风格里挑一个；有参考图就一起给它。

接下来它会先给你一份「计划」，你点头后它才开始出图。

## 风格怎么选

它会先把可选风格的名字列给你，你把想要的那个**名字原样告诉它**就行：

- 2.5D 科研风格
- 平面矢量风格
- 2.5D高级
- 2.5D 柔彩机制图
- 科研流程图
- BioRender 科研插画
- 无风格参考

> 风格必须由你来定，它不会替你默认挑一个。

## 它会问你两件事

1. **用哪种风格？** —— 不选就不往下走。
2. **确认要出图吗？** —— 出图会消耗额度。**没有你明确同意，它不会出图。**

## 出图前后会发生什么

- **先看计划再出图**：它会先告诉你一共几页、用什么风格、有没有参考图、大概出几张；你同意后才真正开始。
- **失败不浪费**：万一某一页失败，让它再跑一次就好——**只会补上失败或缺的那几页**，已经成功的不会重复出图，也不会重复花费。
- **重画要先问**：如果你想重画已经生成的图，它会**先征求你的同意**，不会悄悄覆盖。
- **网络问题**：一般直连即可，通常不需要额外设置；若连接不稳，让它重试或稍后再试。

## 关于授权码

- 授权码是你的「通行证」，请像密码一样保管好。
- **不要**把授权码写进任何文件、发给别人，或提交到网上。
- 只需要填写一次，保存在你本机的用户配置里即可。

## 常见问题

| 你遇到的情况 | 怎么办 |
|---|---|
| 它反复问你风格 | 正常。风格必须由你决定，挑一个告诉它即可 |
| 出图前它停下来问你 | 正常。这是「确认后才出图」的保护，同意后再让它继续 |
| 某一页没出成功 | 让它再跑一次，只会补失败的那几页 |
| 想重画某张图 | 直接说，它会先征求你同意再重画 |
| 连接不稳定 | 让它重试或稍后再试 |

## 进阶（可跳过）

想自己在命令行里运行，可以这样（把 `<...>` 换成你的内容）：

```
python scripts/bio_sketch_figure.py check                                   # 检查环境与授权码
python scripts/bio_sketch_figure.py styles                                  # 列出所有风格
python scripts/bio_sketch_figure.py all "<研究主题>" --style <风格id>        # 只出计划，不出图
python scripts/bio_sketch_figure.py all "<研究主题>" --style <风格id> --confirm   # 同意后出图
```

- 不带 `--confirm` 只会打印计划，**不会出图**。
- 想重画已生成的页，加 `--overwrite`（会先要求你确认），否则默认跳过已生成的页。
